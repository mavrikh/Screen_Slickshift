# pyautogui is used in Step 1 for passive cursor position polling (pyautogui.position())
# and will be used in early injection steps (pyautogui.moveTo/moveRel).
#
# PROVISIONAL -- Known Unknown #2 from Slickshift CLAUDE.md:

# on macOS and SetWindowsHookEx on Windows. That decision is deferred to Step 5
# diagnostics.

# pynput is used for cross-platform mouse button and scroll event capture.
# It runs a listener in a background thread and provides on_click / on_scroll

pynput>=1.7
